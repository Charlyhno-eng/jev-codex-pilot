# Contributions

Suggestions for improvements and bug reports are welcome. Please contact Charly on [X](https://x.com/Charlyhno).

For a bug report, include what you expected, what happened, and the steps to reproduce it. Screenshots or a short recording can help. Please remove passwords, tokens, and other private information before sharing.

Please send feedback and reports only. Do not create branches, push code, or send pull requests; code contributions are not being reviewed.
