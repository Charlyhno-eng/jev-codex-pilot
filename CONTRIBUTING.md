# Contributions

Suggestions, feature requests, code improvement ideas, and bug reports are welcome.

However, **please do not submit any code contributions directly to the repository**. This includes:

* Code changes or modifications
* Bug fixes
* New features
* Improvements or refactoring
* New branches
* Commits or pushes
* Pull requests
* Any other direct contribution to the repository

**All feedback and contribution proposals must be sent directly to me on X.**

Please contact me on [X](https://x.com/Charlyhno) with your suggestion, proposed change, feature request, or bug report. I will review it myself and decide whether and how to integrate it.

For bug reports, please include what you expected to happen, what actually happened, and the steps to reproduce the issue. Screenshots or a short recording can be helpful.

Please make sure to remove passwords, tokens, API keys, and any other private or sensitive information before sharing.

**X is the only channel for contributions, suggestions, feature requests, and bug reports. Please do not open issues or pull requests, create branches, or push code to the repository.**
